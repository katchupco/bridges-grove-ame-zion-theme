Install:
1) WordPress Admin → Appearance → Themes → Add New → Upload Theme
2) Upload the ZIP, activate.

Set up (recommended):
1) Pages → Add New → create a page named "Home"
2) Edit "Home" with the block editor:
   - Click "+" → Patterns → Category "Bridges Grove" → choose "Landing Page (Hero + Cards)"
   - Replace text, buttons, and images as needed.
3) Settings → Reading:
   - "Your homepage displays" → "A static page" → Homepage = "Home"

Header logo:
- Appearance → Customize → Site Identity → Logo (uses WordPress built-in Site Logo)

Footer icon image:
- Appearance → Customize → Bridges Grove Theme Options → Footer → Footer Icon Image

Hero background image:
- Appearance → Customize → Bridges Grove Theme Options → Landing Hero → Hero Background Image

Header buttons:
- Appearance → Customize → Bridges Grove Theme Options → Header Buttons

GitHub updates:
- Appearance → Customize → Bridges Grove Theme Options → GitHub Updates
- Enable GitHub theme updates.
- Optional: enable automatic GitHub theme updates.
- Enter the public GitHub repository URL, such as https://github.com/yourname/bridges-grove-ame-zion
- Optional: enter the exact release ZIP asset name. If the exact file is not found, the updater uses the first ZIP attached to the latest release.
- For future updates, publish a GitHub release with a newer tag such as v2.8.12, then attach the WordPress-ready theme ZIP to that release. WordPress will show the update in Dashboard → Updates after its next update check.
- To test updates: install an older ZIP, configure GitHub Updates, then publish a newer GitHub release. In WordPress, go to Dashboard → Updates and click "Check again".

Menus:
- Appearance → Menus → create a menu and assign it to "Primary Menu" (and optionally "Footer Menu")

Notes:
- The front page template automatically pulls content from pages with these slugs when they exist: about, first-family, our-pastor, events, watch, contact, plan-your-visit.
- Key inner pages now use polished theme-controlled layouts based on the church’s current content. Existing page editor content is preserved inside a collapsed “additional page content” area when it exists.
- If those pages do not exist yet, the home page still shows polished starter content instead of empty placeholders.
- To manage homepage photos: manage the Gallery page/plugin. The homepage extracts those photos and displays a contained preview that links to the full Gallery page.
- To manage events: use The Events Calendar plugin. Add events in Events > Add New, and the Events page will display upcoming plugin events automatically. If that plugin is not active, the theme falls back to its built-in Church Events area.
- To manage the First Family photo: set the First Family page Featured Image, or use Appearance > Customize > Bridges Grove Theme Options > Page Photos.
- To manage the pastor bio: edit the Our Pastor page content. It appears in the Pastor Bio section automatically.
- To manage social media: use Appearance > Customize > Bridges Grove Theme Options > Social Media. Facebook is preset to https://www.facebook.com/BridgesGroveAMEZ.
- To edit the history timeline in the editor: insert the "History Timeline Section" pattern from the Bridges Grove pattern category and edit/add timeline items.
